# Java 工程规范（JavaPilot 检索测试材料）

## 业务正确性
- 金额计算必须使用 `BigDecimal`，折扣比例必须使用可读且精确的十进制表示。
- 为边界条件和关键业务分支编写自动化测试。
- 查询不存在的资源时，应明确映射为合适的 HTTP 状态码，不要把空值当成成功结果返回。

## API 与输入
- 对外部输入做校验；校验失败时返回稳定、可理解的错误结构。
- 不要将内部堆栈、数据库细节或敏感配置返回给客户端。

## 可维护性
- 业务逻辑应放在 Service 层，Controller 负责 HTTP 适配。
- 审查建议必须指出具体文件、行号和代码证据；没有证据时应明确说明不确定性。
- 优先给出最小修复建议，避免在代码审查任务中擅自重写整个模块。
